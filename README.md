# ImmverseAI – Senior QA Automation Engineer Assignment

## Project Overview

This project demonstrates a scalable UI and API automation framework developed using **Playwright and TypeScript** for the ParaBank application.

The framework follows the Page Object Model (POM) design pattern and includes UI automation, API testing, reusable utilities, TypeScript interfaces, and a custom HTML test dashboard.

## Technology Stack

- Playwright
- TypeScript
- Node.js
- Page Object Model (POM)
- REST API Testing
- XML/JSON Parsing
- Git and GitHub
- GitHub Actions
- Custom HTML Dashboard

## Prerequisites

- Node.js (LTS recommended)

## Installation

Clone the repository:

```bash
git clone YOUR_PUBLIC_GITHUB_REPOSITORY_URL
cd ImmverseAI_Assignment
```

Install dependencies:

```bash
npm ci
```

Install Chromium:

```bash
npx playwright install chromium
```

## Execute Tests

Run all tests:

```bash
npx playwright test
```

Run UI tests:

```bash
npm run test:ui
```

Run API tests:

```bash
npm run test:api
```

Run tests in headed mode:

```bash
npm run test:headed
```

## Custom HTML Dashboard

The framework includes a custom HTML dashboard generated by the custom Playwright reporter.

The dashboard presents test execution results using a glassmorphism-style interface with **#F48031** as the accent color.

Generate the dashboard by running:

```bash
npx playwright test
```

Open the generated dashboard in Windows PowerShell:

```powershell
start .\reports\index.html
```

## Automated Test Scenarios

### Scenario A – User Registration, Account Creation and Loan Approval

- Generate unique registration data.
- Register a new customer through the UI.
- Retrieve customer and account details through the API.
- Open a Checking account.
- Apply for a loan using dynamic account IDs.
- Validate loan approval and the loan account balance.

### Scenario B – Fund Transfers and Transaction Validation

- Perform three transfers: $150.00, $25.50 and $8.99.
- Navigate to Find Transactions.
- Extract and parse transaction table data.
- Calculate outgoing transfers using integer cents.
- Verify the total deduction against the account balance.

### Scenario C – API Testing

- Retrieve customer information through the REST API.
- Deposit funds into an account.
- Retrieve transaction history.
- Validate response status, transaction details and TypeScript data structure.

**API limitation:** The public ParaBank API does not expose a customer-creation endpoint. The API scenario therefore uses an available demo customer rather than creating a new customer through the API.

## CI/CD

A GitHub Actions workflow is included under `.github/workflows/playwright.yml`.

The workflow can be triggered manually from the GitHub Actions tab. It executes the tests and uploads the custom dashboard as an artifact.

## Design Decisions

Refer to [DECISIONS.md](DECISIONS.md) for details about:

- Test data management and concurrency.
- Shared database reset considerations.
- Financial calculations and floating-point precision.
- API versus UI testing boundaries.
- Public ParaBank API limitations.

**Important:** ParaBank is a public shared test environment. Tests can create users, accounts, deposits and transfers. Avoid destructive database reset operations on the shared environment.
